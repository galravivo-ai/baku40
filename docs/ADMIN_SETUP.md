# ממשק הניהול (/admin/): חיבור חד־פעמי

ממשק הניהול הוא Decap CMS (החלופה החינמית שמותרת ב‑`CMS_Spec.md`). הוא עורך את אותם קבצי `content/*.json`. כל שמירה יוצרת commit ב‑GitHub, ו‑Vercel בונה את האתר מחדש תוך 1–2 דקות.

רק מי שיש לו הרשאת כתיבה למאגר `galravivo-ai/baku40` ב‑GitHub יכול לשמור. אין גישה ציבורית.

## שלב 1: אפליקציית התחברות ב‑GitHub (פעם אחת)
1. GitHub ← Settings ← Developer settings ← OAuth Apps ← **New OAuth App**.
2. Application name: `Baku40 Admin`.
3. Homepage URL: `https://baku40.vercel.app`
4. Authorization callback URL: `https://baku40.vercel.app/api/decap/callback/`
5. שומרים, מעתיקים את **Client ID**, ולוחצים **Generate a new client secret** ומעתיקים גם אותו.

## שלב 2: משתני סביבה ב‑Vercel
Vercel ← הפרויקט ← Settings ← Environment Variables:
- `GITHUB_OAUTH_CLIENT_ID` = ה‑Client ID
- `GITHUB_OAUTH_CLIENT_SECRET` = ה‑Client secret

אחר כך: Deployments ← שלוש נקודות ← **Redeploy**.

## שלב 3: כניסה
נכנסים ל‑`https://baku40.vercel.app/admin/` ולוחצים "התחברות עם GitHub".

## כשעוברים לדומיין baku40.co.il
ב‑OAuth App ב‑GitHub מעדכנים את שתי הכתובות לדומיין החדש. בממשק עצמו אין מה לשנות.

## מה אפשר לערוך
- **הגדרות:** שם האתר, תפריט, פוטר, גילוי נאות, SEO לעמודים קבועים, הפניות 301, הצגת תמונות Booking/עיר.
- **עמודים:** דף הבית, עמוד האטרקציות, אזורים.
- **אוספים:** מלונות, מסעדות, כשר, מסלולים, קניות, טיולי יום.
- **עמודי תוכן:** מדריך, השקעות, נדל״ן, קזינו, מידע למטייל, מגזין ועוד. אפשר גם ליצור עמוד חדש.

## כללים שנבדקים אוטומטית
- כותרת לגוגל עד 65 תווים, תיאור עד 155. כותרת או תיאור כפולים באתר מכשילים את הבנייה.
- בכל רשומה `name` ו‑`text` הם שדות חובה. קישור Booking חייב להתחיל ב‑`https://www.booking.com/`.
- תמונה שמועלית מהממשק מוצגת רק אם בשדה "רישיון תמונה" נבחר "מורשה" או "הדמיה". הדמיה מקבלת תווית "הדמיה, לא צילום".
- אם קובץ שבור, הבנייה ב‑Vercel נכשלת והאתר הקודם נשאר באוויר. ההודעה ב‑Build Logs אומרת איזה שדה צריך לתקן.

## מה עוד לא אוטומטי
- **שינוי slug:** הפניה מהכתובת הישנה לא נוצרת לבד. מוסיפים אותה ידנית בלשונית "הפניות (301)".
- **`image-sources.json`:** לא נערך מהממשק, אלא ב‑GitHub.
- **השמירה הראשונה של כל קובץ:** הממשק מסדר מחדש את סדר השדות בקובץ. זה לא משנה את התוכן.
