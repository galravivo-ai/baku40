## 2. מסעדות תחת פיקוח

השאלה הקריטית. כרגע האתר **אינו** מסמן אף מסעדה ככשרה, וזו המדיניות הנכונה עד שיש תשובה.

| מה לשאול | תשובה |
|---|---|
| האם קיימת מסעדה בבאקו תחת פיקוח כלשהו כרגע | |
| אם כן — שם, כתובת, ומי הגורם המפקח | |
| האם הפיקוח קבוע או לפי אירוע | |
| האם יש תעודה בתוקף שניתן לראות, ומה תאריך התפוגה | |
| מה מומלץ לומר לתייר ששואל "אפשר לאכול שם?" | |

> אם התשובה היא "אין כרגע" — זו תשובה מלאה וטובה. נכתוב אותה במפורש עם תאריך, ונשאיר את הפילטר "כשר מאומת" מחזיר אפס תוצאות.

## איך זה חוזר לאתר

1. כל תשובה נכנסת לשדה ב‑CMS עם **שם המקור** ו**תאריך הבדיקה**.
2. רשומה שקיבלה מענה עוברת לתג ירוק. רשומה בלי מענה נשארת "ממתין לאימות" — ולא מתפרסמת כעובדה.
3. אם התשובה היא "אין", היא נכתבת כ"אין, נבדק בתאריך X" — זה מידע מועיל בפני עצמו, לא כשל.
4. תאריך הבדיקה מופיע בעמוד, כדי שהקורא ידע עד כמה המידע טרי.

**עקרון מנחה:** בכשרות, טעות לכיוון המקל היא הנזק הגדול. בספק — לא מסמנים.
